## Swarm-SDK
This project was created to simplify the creation of your own games on the Alien Swarm engine branch. It uses the ported Source 2007 SDK template by [Krispy](https://github.com/FriskTheFallenHuman/swarm-sdk-template/tree/master) for Alien Swarm with some changes and fixes.

## Features
- Added NextBot AI (Ported from Source SDK 2013)
- Updated ShaderCompile to 2.0
- Fixed NavMesh for NextBots
- Fixed player spawn
- Fixed some game bugs
- Fixed shaders building
- Removed teams, classes, MOTD and some stuff...

## How to build
1. Install Visual Studio 2013 Community Update 5
2. Clone this repository 
3. Open everything.bat (or games.bat) to create .sln file
4. Open .sln file and build solution
5. Well done
